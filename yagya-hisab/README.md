# YagyaHisab — यज्ञ हिसाब

A lightweight, installable web app for Nepali and English financial calculations.

## Features
- Loan EMI / monthly instalment estimate
- Simple and compound interest
- SIP monthly investment projection
- Percentage and change calculations
- Nepali and English interface
- Offline support after the first successful visit
- Responsive layout for Android phones and desktop browsers
- Calculations happen on your device; values are not uploaded to a server

## Open the app
https://aupadhaya888-ctrl.github.io/Rayyoka-/yagya-hisab/

## Install on Android
1. Open the app link in Google Chrome while connected to the internet.
2. Wait for the page to finish loading.
3. Tap **Install on phone** if shown. Alternatively, open Chrome's ⋮ menu and choose **Install app** or **Add to Home screen**.
4. Open the new YagyaHisab icon from your home screen.
5. After the app has loaded successfully once, its cached app shell can be used offline.

## Important
This is an installable Progressive Web App (PWA), not yet a signed APK. Publishing a standalone APK or Play Store release requires a separate Android packaging and signing step. Financial outputs are estimates, not financial advice.
